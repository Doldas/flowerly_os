# Online Help

This section is the user-facing help center for Flowerly OS.

## Today

Flowerly OS is currently an early development system. Most interaction is through the repository tooling and `agenticctl`, not a finished desktop shell.

Useful pages:

- [Getting Started](getting-started.md) — build and run the current development runtime.
- [Flows](flows.md) — what a Flow is and what is implemented versus planned.
- [Troubleshooting](troubleshooting.md) — common development-runtime problems.
- [Build Guide](../build.md) — deeper build information.
- [Roadmap](../roadmap.md) — when major capabilities are expected.

## Help philosophy

Future Flowerly OS help should be contextual. A user should be able to ask the system what something is, why it changed, or how to accomplish a goal without needing to understand the implementation first.

Until that interface exists, this site is the canonical online help.
