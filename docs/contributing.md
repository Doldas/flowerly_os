# Contributing

Flowerly OS welcomes contributions, but the project deliberately evolves one real primitive at a time.

For the full contribution policy, see the repository [CONTRIBUTING.md](https://github.com/Doldas/flowerly_os/blob/master/CONTRIBUTING.md).

Before changing architecture:

1. Read the [Vision](vision.md).
2. Read the [Architecture](architecture.md).
3. Check the [ADRs](adr/index.md).
4. Check the active [Roadmap](roadmap.md) milestone.
5. Add or propose an ADR when a change affects a foundational decision.

All code should leave the repository buildable and should include the relevant tests and documentation.
